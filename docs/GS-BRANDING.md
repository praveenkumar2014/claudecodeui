# GS Branding System

Use the owner-supplied GS logo as the parent product mark. Keep the mark's proportions and color geometry unchanged. Generate app icons/favicon sizes from the supplied SVG/PNG; do not substitute a stock icon.

Two original agent identity directions:
- Agent Brain: circular neural/agent motif derived from the GS monogram's internal geometry.
- Remote Work Brain: structured workspace/terminal motif derived from the same stroke and circle language.
These must be visually distinct at 24px and recognizable in monochrome. Parent GS mark remains common; runtime color/shape accents distinguish brain types.

Do not reuse NanoBot cat mark, CloudCLI logo, Claude logo or Codex logo as GS agent identities. Provider logos can appear only as truthful provider attribution in integration settings.

Maintain upstream attribution and license files; branding changes must not conceal authorship or ownership of upstream code.
